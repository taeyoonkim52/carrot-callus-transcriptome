# R1 secondary protocol — frozen before membership and sensitivity evaluation

2026-11-15. Existing primary findings are already known. This is an expert-response protocol, not preregistration. No primary fit, universe, original FDR, core membership or primary enrichment is replaced.

Canonical panel: Arabidopsis WIND1/2/3/4; LBD16/18/29; WOX11; PLT1/2/3/5/7; ARF7/19; SERK1/2/3/4/5; BBM; LEC1/2. Resolve stable loci using primary papers and curated gene records before joining to fixed core/interaction membership. Keep every panel member including unmapped and non-core findings. Orthology is not proof of conserved regulatory function.

Orthology method: Ensembl Plants BioMart Compara carrot-to-Arabidopsis orthology, bridged to the DH1 v3 NCBI GeneIDs by explicit NCBI GeneID cross-reference only. Ensembl carrot is the older ASM162521v1 assembly: document cross-version limitations, never equate numeric DCAR loci to NCBI GeneIDs. Main functional transfer uses high-confidence Compara records with a unique NCBI-to-Ensembl bridge. Union Arabidopsis GO assignments across qualifying one-to-many orthologs; count each carrot gene once per term. Ambiguous bridges are excluded; all unmapped/low-confidence records remain reported. Contemporary retrieved Ensembl GO and its hierarchy form an additional annotation layer. Exclude NOT/obsolete annotations where represented; BioMart annotation limitations must be explicit. Background is expressed 24,961 intersect usable orthology and non-root GO annotation. Test all GO terms with 5–5,000 background genes separately for core/all, core/up, core/down, practical interaction and LARGE interaction; one-sided hypergeometric, global BH across all five families; retain null results and contributing genes. No KEGG unless independently defensible mapping exists.

LFC checks: keep the original significant interaction set fixed. A: approximate multivariate normal posterior shrinkage of the four fitted response contrasts, using the saved NB fit's HMH covariance and independent N(0,tau^2) priors on four log2 responses, tau=1 and tau=2. Posterior mean tau^2(Sigma+tau^2 I)^-1 b. This is a normal-likelihood sensitivity, not apeglm, not new hypothesis testing, and may over-shrink genuine large effects. Do not call single-coefficient lfc_shrink on a maximum-minus-minimum range. B: keep original effects, require CPM>=1 in >=2 of 3 dishes in EACH of eight genotype-time cells; companion CPM>=5 rule. This intentionally tests well-supported two-sided effects, excludes genuine on/off responses, and is not a replacement universe. Report bins <0.5, 0.5–<1, >=1, retained n, practical n/original universe, tails and support. ROBUST if practical heterogeneity >=10% of original universe and LARGE >=50% under all four checks; PARTIALLY_ROBUST if broad practical heterogeneity persists but LARGE dominance fails; NOT_ROBUST if substantive heterogeneity does not persist. Interpret together with preserved primary descriptive and omission evidence, not tail sizes alone.

No n=4 phenotype association, late-stage primary model, manuscript editing, new release, commit or push.
