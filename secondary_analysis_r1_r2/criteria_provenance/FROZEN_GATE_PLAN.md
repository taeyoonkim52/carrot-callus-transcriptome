# Frozen interaction architecture gate

Scope: the existing 24 Day0/Day20 libraries, fixed 24,961-gene universe and prior fitted model. Prior commit d90bf293f059782df2d52c2a1da117b5d46afce7 and all its outputs remain unchanged. No raw-data processing or new expression question. Previous functional results are already known; this gate does not select categories or thresholds from new enrichment.

Effect metric: each gene's four fitted NB Day20-minus-Day0 log2 fold changes. Maximum absolute pair difference equals max-minus-min response range (report both, do not imply distinct evidence). Median difference is median of the six absolute pair differences. SMALL range <0.5, MODERATE 0.5 <= range <1, LARGE range >=1 log2 unit. These correspond to <1.41, 1.41-2 and >=2-fold ratios between genotype responses. They are practical operational thresholds, not validated phenotypic effect thresholds. FDR remains 0.05.

Leave-one-genotype-out: refit identical PyDESeq2 ~genotype*time NB model on 18 dishes, using unchanged imported counts and full fixed gene universe. Joint two-df interaction Wald test, same covariance implementation and Cook/convergence validity filters as prior analysis. BH separately in each sensitivity fit. Report significant and practical (FDR<=0.05 AND range>=0.5) genes over the original universe; also report retention within the original 15,053 interaction genes. Substantial practical heterogeneity: >=10% of original universe. ROBUST if all four omissions retain substantial heterogeneity; PARTIALLY_ROBUST if 2 or 3 do; SINGLE_GENOTYPE_DRIVEN if exactly one omission fails and >=80% of original practical genes lose significance/practical effect in that omission; otherwise classify partial with explicit uncertainty. No causal driver attribution.

Pairwise: all six log2(CPM+1) response vectors over fixed universe; Pearson, Spearman, cosine, direction agreement, RMS ratio. Strong discordance = opposite-signed fitted NB effects with both magnitudes >=0.5; give whole-universe and original-interaction denominators. Descriptive pattern candidates: unique one-outlier if other triplet median Pearson >=0.5, cross-outlier median <=0.2, gap>=0.3; two-group if within-pair median>=0.5, cross-pair median<=0.2, gap>=0.3. Evaluate all four singleton and three two/two partitions, require >=80% bootstrap support and same selection in >=80% of dish omission sensitivities. This describes topology, not biological categories. Otherwise continuous divergence if stable heterogeneous response; no stable structure if replicate relationships fail. An outlier topology alone does not establish one-genotype-driven interaction.

Replicate stability: all 24 leave-one-dish-out refits of unchanged eight-parameter NB model on 23 libraries; no permanent sample exclusions. Separately compute descriptive response relationships under each omission. Fixed core membership never redefined: record original-core criterion retention, sign retention and effect range in each sensitivity fit. Also 2,000 independent-dish bootstrap resamples within eight genotype/time cells, seed 20261005, assess transformed-response direction stability for original core. This bootstrap checks observed bulk response signs, not NB FDR or equivalence. Gene robust if same original NB direction across all four bootstrap responses in >=90% resamples AND original core criteria retained in >=80% of dish omissions. ROBUST_CORE if >=80% of 968 meet both; PARTIAL_CORE if >=50%; otherwise UNSTABLE_CORE. Heterogeneity stable if practical significant fraction >=10% in >=80% of dish omissions and all pair correlations change by <=0.2 in >=80% omissions. Report thresholds and raw sensitivities, do not treat small n bootstrap as population validation.

Freeze architecture/core results BEFORE new enrichment. Functional tests: fixed prior core split up/down, and original FDR interaction genes with response range>=0.5 only. Twelve predefined GO roots: cell cycle GO:0007049; cell division GO:0051301; chromatin GO:0006325; auxin GO:0009733; cytokinin GO:0009735; wound GO:0009611; stress GO:0006950; cell wall GO:0071555; meristem GO:0010073; developmental process GO:0032502; photosynthesis GO:0015979; primary metabolism GO:0044238. Reuse pinned reference GAF/ontology. is_a/part_of descendants, omit NOT/obsolete records. Annotated genes in full expressed universe are testable background; report unannotated fraction. BH over all 36 tests. No unrestricted GO search, candidate genes, mechanistic genotype narrative, or unexpected category additions. Photosynthesis suppression requires negative core effects.

Architecture primary decision order: UNSTABLE if replicate stability fails; WEAK_EFFECT_STATISTICAL if >=80% original interaction genes SMALL; ONE_GENOTYPE_DOMINATED if singleton omission explains >=80% original practical signal while other omissions remain substantial; BROAD_GENOTYPE_SPECIFIC if >=50% original interaction genes practical, all four omissions substantial, no singleton dominates, and replicate stable; otherwise INCONCLUSIVE. PAPER PASS requires BROAD_GENOTYPE_SPECIFIC + ROBUST_CORE; CONDITIONAL_PASS if broad architecture + PARTIAL_CORE or robust core + inconclusive architecture; otherwise FAIL. Recommend A PROCEED_TO_PAPER for PASS/CONDITIONAL_PASS (conditional work limited to PI review of evidence); C STOP_PROJECT for FAIL. No late-stage analysis to rescue this gate.
