# Execution order and input/output contracts

The retained numerical results are immutable inputs to this candidate. All commands below are instructions for future independent reproduction, not steps executed during archive preparation. Run commands from the repository root in a fresh environment.

1. Accession mapping: metadata/sample_manifest.tsv and accession_crosswalk.tsv identify 24 Day0/Day20 libraries. Each dish is a biological replicate; suffixes do not establish pairing across time.
2. Raw acquisition (optional, requires public external data): `python scripts/prepare_workspace.py raw`. Install the recorded tools. One production sample, C815_20d_3 / SRR36683244, uses full-quality SRA conversion after an original repository read-quality problem. Run dedif_sra_fallback.py before dedif_acquire.py so its derived file metadata is present. The fallback requires the original toolkit ZIP in work/dedifferentiation/tools/ and its extracted sratoolkit/bin tools, an isolated sra_user_settings.mkfg, and existing fastq/log directories. Four retained spot ranges are documented in provenance/sra_fallback_provenance.json. Gzip container hashes can differ on independent conversion; verify content/spot count and record regenerated hashes. Never substitute SRA Lite. Other source URLs/MD5 values are in metadata/fastq_sources_original_repository.tsv.
3. References: retrieve each file from provenance/reference_resources.tsv into work/dedifferentiation/reference/, preserving recorded filenames and checking MD5/SHA256. dedif_acquire.py writes reference_manifest.tsv and invokes dedif_reference_audit.py to build transcript-to-gene and identical-sequence records; do not invoke the audit before that manifest exists. No references are bundled.
4. Full-file QC: dedif_prepare_fastqc.py prepares the recorded FastQC and Java distributions, then run dedif_fastqc.py. The workflow's expected local tool layout is documented by these scripts; Windows executable paths are runtime-relative.
5. Kallisto: install 0.50.1 at work/dedifferentiation/tools/kallisto.exe. Run dedif_quantify.py, which builds/reuses the index and quantifies unstranded paired-end libraries with eight production threads (four in the pilot). Production reference/index and executable hashes are in provenance/quantification_software.json.
6. Aggregation/technical QC: dedif_technical_gate.py consumes quantification COMPLETE.json markers, abundance files, full-file FastQC ZIP files and transcript mappings. It writes gene counts/TPM/effective lengths, library/QC records and technical_expression_unicode.npz. It excludes cross-gene identical-sequence ambiguity and retains CPM >=1 in at least three libraries, giving the frozen 24,961-gene universe. The Unicode gene-ID checkpoint is a storage adaptation only.
7. Derived-only primary reproduction: prepare_workspace.py primary seeds the retained numerical checkpoint, metadata, gene universe and historical PASS input-QC record. It does not claim to rerun raw QC. dedif_primary_analysis.py computes descriptive PCA/global variance, response vectors/similarities and genotype dispersion; resampling is within genotype/time cells. Seed 20261004; 2,000 bootstraps.
8. The same primary script fits the frozen PyDESeq2 negative-binomial model ~genotype*time using integer lengthScaledTPM counts; genotype×time uses the original joint three-degree-of-freedom Wald test and covariance. Gene validity, Cook/convergence handling, BH and all original thresholds remain in code. This is an unpaired design.
9. prepare_workspace.py architecture seeds retained primary inputs and both checkpoints for independent architecture reproduction. interaction_architecture.py computes response-range effect architecture and topology; seed 20261005, 2,000 bootstraps.
10. That script fits four genotype-omission models (18 samples, two-degree-of-freedom interaction) and 24 dish-omission models (23 samples, three-degree-of-freedom interaction), keeping the fixed universe. Four parallel workers are retained.
11. The original shared-core definition requires common direction, minimum absolute response >=0.5 log2, response range <=1 and time BH <=0.05. Membership remains fixed for stability. The secondary stability criteria are direction bootstrap probability >=0.9 and original-criteria omission retention >=0.8.
12. Functional_annotation.py completes omission effect-size details and GO annotation after architecture outputs exist. Retrieve the pinned go-edit.obo from provenance/ontology_provenance.json and GAF from reference_resources.tsv into work/dedifferentiation/reference/. It uses twelve predefined categories and three queries, with a single joint 36-test BH family and annotated-gene background. Unannotated genes and absent category backgrounds are explicitly retained as limitations.
13. Figure reproduction alone requires no raw data or new statistical fitting: render_figures.py reads figures/source_data/ and S1–S9, writing PDF/SVG/PNG to figures/reproduced/. Some figure labels contain frozen summary numbers intentionally preserved from the original renderer.

Runtime tables go to outputs/dedifferentiation_gate/ or outputs/interaction_architecture_gate/; models/intermediates go to work/. These historical directory names are execution plumbing, not redistributed internal review reports. Do not overwrite results/ or figures/source_data/. Scripts refuse completed primary outputs; workspace seeding refuses conflicting existing inputs. Supplementary tables are retained frozen outputs; no new table-packaging analysis is executed by this archive.
